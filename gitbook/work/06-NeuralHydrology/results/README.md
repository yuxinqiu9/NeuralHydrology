# Results

This folder stores model evaluation outputs.

## Files (populated after running showcase.py or nh-run evaluate)

| File | Description |
|------|-------------|
| `model_comparison.csv` | NSE/KGE scores per model (generated by showcase.py) |
| `synthetic_discharge.csv` | Synthetic time series for plotting (showcase.py demo mode) |
| `test_results.p` | Pickle file with full evaluation results (nh-run evaluate output) |

## Loading Results in R

```r
library(readr)
library(ggplot2)

# Load model comparison
results <- read_csv("results/model_comparison.csv")
ggplot(results, aes(x=model, y=nse_test, fill=type)) +
  geom_bar(stat="identity") +
  coord_flip() +
  labs(title="Model NSE on CAMELS-US (basin 01013500)",
       x=NULL, y="NSE (test period)")

# Load discharge time series
ts <- read_csv("results/synthetic_discharge.csv")
ggplot(ts, aes(x=date)) +
  geom_line(aes(y=observed_mm_day, color="Observed")) +
  geom_line(aes(y=predicted_mm_day, color="EA-LSTM"), linetype="dashed") +
  labs(x=NULL, y="Discharge [mm/day]", color=NULL)
```
